## 📚 Marco Teórico

### ¿Qué es un Framework CSS?
Un **Framework CSS** es un conjunto  de archivos, reglas de estilo, componentes visuales y utilidades creados para simplificar y agilizar el proceso de desarrollo e interfaz web (*frontend*). 

En lugar de escribir todo el CSS desde cero para cada proyecto, un framework proporciona:
* **Estandarización:** Mantiene un diseño visual y una estructura de código limpia.
* **Sistemas de Rejilla (Grids):** Facilita la creación de diseños adaptables a cualquier pantalla (*Responsive Design*).
* **Velocidad de Desarrollo:** Permite construir interfaces complejas en una fracción del tiempo habitual.
* **Compatibilidad:** Garantiza que los estilos se visualicen de forma coherente en distintos navegadores.


## ⚔️ Comparativa: Bulma vs. Tailwind CSS

* Aparte de que tanto Bulma como Tailwind son frameworks CSS de código abierto para el desarrollo sencillo de interfaces web, no existen muchas similitudes entre ambos. Si bien ambos buscan simplificar el desarrollo de interfaces de usuario, cada uno adopta un enfoque fundamentalmente diferente para abordar este problema.
* Bulma proporciona una plantilla lista para usar, mientras que Tailwind ofrece todas las herramientas necesarias para que un desarrollador cree su propia plantilla.




## 📊 Cuadro Comparativo

| Característica | Bulma CSS | Tailwind CSS |
| :--- | :--- | :--- |
| **Paradigma** | Orientado a Componentes | Utility-First (Clases atómicas) |
| **Curva de Aprendizaje** | Baja (Muy intuitiva) | Media / Alta (Requiere memorizar utilidades) |
| **Personalización** | Moderada (requiere Sass o CSS) | Total (desde HTML o configuración) |
| **Caso de Uso Ideal** | Prototipado rápido y webs estándar | Aplicaciones web a medida y escalables |

## 💻 Requisitos Previos

- Para visualizar y probar este proyecto de forma local solo necesitas:
- Tener un sistema operativo <Windows / Linux / Mac>
